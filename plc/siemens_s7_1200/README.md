# Siemens S7-1200

Папка предназначена для материалов тестового проекта аппаратного PLC.

Сюда помещаются:
- описание проекта;
- экспорт таблиц тегов;
- экспорт блоков, если применимо;
- скриншоты настроек CPU;
- сведения о версии firmware;
- архив проекта TIA Portal, если принято хранить его в рабочем архиве.
