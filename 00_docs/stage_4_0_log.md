# Этап 4.0. Подготовка экспериментальной реализации стенда

## Цель этапа

Подготовить программную, системную и измерительную инфраструктуру для проведения экспериментальных серий по методике ВКР.

## Текущее состояние

Физический стенд собран.  
Оборудование подключено.  
Программная подготовка mini-PC, PLC и инженерной машины находится в начальной стадии.

## План работ

1. Создать рабочую папку экспериментов `VKR_Experiments`.
2. Сделать начальный `ManifestCfg` стенда.
3. Установить ОС на mini-PC.
4. Настроить сеть.
5. Проверить связь `ENG_NODE ↔ VPLC_HOST ↔ HW_PLC`.
6. Установить базовые утилиты.
7. Снять первый конфигурационный снимок mini-PC.
8. Установить Podman.
9. Проверить VPLC/VPLC Server в Linux CLI-режиме.
10. Проверить штатный bare-metal workflow VPLC Studio ↔ VPLC_HOST и создать минимальный тестовый проект VPLC.
11. Реализовать контейнерный профиль запуска через Podman после понимания штатного workflow.
12. Закрыть инфраструктурную проверку `HW_PLC` / S7-1200 без дополнительного счётчикового smoke-test.
13. Разработать сопоставимые прикладные программы нагрузки для `vPLC_container` и `HW_PLC`.
14. Определить карту метрик, формат `RawLogs` и процедуру съёма данных.
15. Сделать первый короткий прогон.
16. Проверить сбор `RawLogs`.
17. Написать первый `process_logs.py`.
18. Провести пробные прогоны.
19. Провести baseline/stress серии.
20. Подготовить артефакты для написания Главы 4.
