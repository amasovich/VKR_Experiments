# Инженерная шкала GREEN / YELLOW / RED для Главы 4

Дата фиксации: 2026-05-11.

Статус: зафиксировано для практической части ВКР.

Основание: методика оценки детерминизма и стабильности цикла управления, подпункт 2.5, формула (2.26), таблицы А.13 и А.14.

Профиль порогов: `configs\mode_thresholds.yaml`, версия `1.0`, статус `calibrated_for_vkr_chapter_4`.

Класс сценария: умеренно критичный циклический контур управления / технологической автоматики без функций ПАЗ/SIL.

## Смысл статусов

| Статус | Инженерная трактовка |
|---|---|
| GREEN | Режим пригоден с запасом для выбранного класса сценария |
| YELLOW | Режим потенциально применим, но требует инженерного контроля, резерва или повторной проверки |
| RED | Режим не рекомендуется как рабочий для выбранного класса сценария |

## Итоговая шкала

| Критерий | GREEN | YELLOW | RED |
|---|---:|---:|---|
| `Q99(Tper)` | `<= 0.90 * deadline` | `<= 1.00 * deadline` | выше |
| `Q99.9(Tper)` | `<= 1.00 * deadline` | `<= 1.20 * deadline` | выше |
| `Rmiss` | `0` | `<= 0.01` | выше |
| `Lburst` | `0` | `<= 1` | выше |
| `valid_ratio` | `1.00` | `>= 0.99` | ниже |
| hard-fail `Rmiss` | - | - | `>= 0.05` |
| hard-fail `Lburst` | - | - | `>= 5` |
| hard-fail `valid_ratio` | - | - | `< 0.95` |

## Отдельная трактовка stress-режима

Для режимов `S7_L3_STRESS_75_80` и `VPLC_L3_STRESS_75_80` зафиксирована роль `stress_boundary`.

Дополнительное правило:

| Параметр | Значение |
|---|---:|
| `yellow_rmiss_max` | `0.03` |

При этом критерии `Q99(Tper)` и `Q99.9(Tper)` для stress-режима не смягчаются.

Если stress-режим получает статус RED, это трактуется как достижение или пересечение границы устойчивости при намеренно жёстком deadline, а не как ошибка постановки эксперимента.

## Примечание о применимости

Шкала является калиброванной для данного эксперимента и выбранного класса сценария. Она не является универсальной нормой для всех технологических процессов, всех классов ПЛК или всех задач реального времени.

Численные KPI (`Q99`, `Q99.9`, `Rmiss`, `Lburst`, `valid_ratio`) рассчитываются из RawLogs независимо от цветовой интерпретации.
