## Ограничения фиксации

Содержимое `Main [OB1]` на данном скриншоте не раскрыто, поэтому логика программы пока не описывается как подтверждённая.

Рабочий каталог TIA Portal не включается в git как обычный исходный код, поскольку содержит крупные и служебные бинарные файлы проекта. В репозитории фиксируются карточка проверки, скриншоты и manifest. Архив проекта TIA Portal (`.zap*`) можно подготовить отдельным шагом, если потребуется воспроизводимый перенос проекта.

## Итог для инфраструктурной проверки

Доступность PLC из Windows подтверждена:

```powershell
Test-NetConnection 192.168.10.10
```

Результат:

```text
PingSucceeded: True
RTT: 2 ms
```

Для данного smoke-test дополнительная логика в `Main [OB1]` не добавляется: оператор подтвердил, что типовые тесты со счётчиком уже выполнялись ранее и сейчас не являются целью этапа.

Текущая аппаратная проверка считается достигнутой: аппаратная конфигурация создана, IP назначен, проект загружен, CPU доступен по сети и находится в `RUN`.

После принятия DEC-006 этот артефакт закрывает только инфраструктурную проверку `HW_PLC` в пункте 12 этапа 4.0. Он не фиксирует workload-логику для сравнительных серий и не является экспериментальным прогоном.

Перед первым коротким прогоном нужно отдельно подготовить сопоставимую workload-программу для S7-1200, определить метод съёма `RawLogs` и зафиксировать, нужен ли переносимый архив TIA-проекта (`.zap*`) как дополнительный воспроизводимый артефакт.
