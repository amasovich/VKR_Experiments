# VKR_Experiments

Рабочий каталог экспериментальной части ВКР.

Тема ВКР: «Методика оценки детерминизма и стабильности цикла управления виртуальных программируемых логических контроллеров в контейнерной среде в сравнении с аппаратными контроллерами».

## Назначение каталога

Каталог предназначен для хранения:

- конфигураций экспериментального стенда;
- скриптов сбора и обработки данных;
- первичных журналов экспериментов;
- обработанных таблиц результатов;
- итоговых карточек режимов;
- экспортов, скриншотов и архивов прогонов;
- материалов для последующего написания Главы 4 ВКР.

## Основные узлы стенда

| Узел | Обозначение | Назначение |
|---|---|---|
| Siemens S7-1200 CPU 1215C | HW_PLC | аппаратный эталонный PLC |
| mini-PC MLLSE G2 Pro | VPLC_HOST | узел исполнения VPLC MAX Automation |
| инженерная машина Windows | ENG_NODE | настройка, сбор, обработка и архивирование данных |
