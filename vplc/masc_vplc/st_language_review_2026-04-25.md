## Что подтверждено

VPLC Studio предназначена для разработки ST-программ, сборки проекта и загрузки проекта в VPLC.

Встроенная документация содержит структуру разделов по языку ST:

- обзор;
- синтаксис и лексика;
- типы данных;
- операторы;
- управляющие конструкции;
- встроенные функции;
- функциональные блоки;
- организация программы;
- примеры программ.

## Ограничение текущей документации

На момент проверки основные страницы по синтаксису, типам данных, операторам, управляющим конструкциям, функциональным блокам, организации программы и примерам программ содержат пометку `Раздел в разработке...`.

Подробно заполнена в основном документация по встроенным функциям.

## Видимые категории встроенных функций

В документации Studio присутствуют категории:

- массивы;
- битовые операции;
- сравнение;
- математика;
- работа с памятью MW;
- упаковка и распаковка;
- строки;
- преобразование типов;
- прочие функции.

По именам функций в документации видны, в частности:

- арифметика: `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `ABS`, `SQRT`, `SIN`, `COS`, `TAN`;
- сравнение: `EQ`, `NE`, `GT`, `GE`, `LT`, `LE`;
- битовые операции: `GET_BIT`, `SET_BIT`, `TOGGLE_BIT`, `SHL`, `SHR`, `ROL`, `ROR`;
- строки: `CONCAT`, `FIND`, `LEFT`, `RIGHT`, `MID`, `LEN`, `REPLACE`, `TRIM`;
- преобразования типов: `BOOL_TO_*`, `INT_TO_*`, `REAL_TO_*`, `STRING_TO_*`;
- служебный вывод в примерах: `SYSLOG(...)`.

## Практический вывод для первого проекта

Первый тестовый проект не должен зависеть от таймеров, функциональных блоков, внешних I/O, Modbus или VPLC Server.

Рекомендуемый первый сценарий:

```text
cycle_counter : UDINT
toggle_flag   : BOOL
```

Логика:

- на каждом цикле увеличивать `cycle_counter`;
- переключать `toggle_flag` по простому условию, например по чётности или достижению порога;
- вывести переменные в мониторинг Studio;
- после успешной сборки и загрузки проверить `vplc status`.

Синтаксис и размещение переменных нужно подтвердить непосредственно через интерфейс Studio, потому что документация по базовой структуре ST пока неполная.
