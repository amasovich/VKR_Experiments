# План сетевой адресации стенда

## Назначение

Документ фиксирует план сетевой адресации экспериментального стенда ВКР.

## Узлы стенда

| Узел | Обозначение | Роль | IP-адрес | Примечание |
|---|---|---|---|---|
| Инженерная машина Windows | ENG_NODE | настройка, мониторинг, обработка, архивирование | 192.168.10.30 | VS Code, TIA Portal, VPLC Studio, Python; адрес использовался как `SourceAddress` при проверках стенда |
| mini-PC Linux | VPLC_HOST | исполнение VPLC / VPLC Server / Podman | 192.168.10.20 | MLLSE G2 Pro; интерфейс `enp2s0`, постоянная netplan-конфигурация проверена после reboot |
| Siemens S7-1200 CPU 1215C | HW_PLC | аппаратный эталонный PLC | 192.168.10.10 | 6ES7 215-1HG40-0XB0; адрес назначен в TIA Portal, доступность с `ENG_NODE` проверена |

## Стендовый сегмент

192.168.10.0/24

## Зафиксированные адреса

| Узел | IP |
|---|---|
| HW_PLC | 192.168.10.10 |
| VPLC_HOST | 192.168.10.20 |
| ENG_NODE | 192.168.10.30 |

> Примечания:
> - DHCP для стендового сегмента не используется.
> - На время измерений внешний сетевой трафик и временный Wi-Fi на `VPLC_HOST` должны быть отключены.
> - При изменении адресации нужно обновить `configs/stand_manifest_initial.yaml`, `configs/mode_matrix.yaml` при необходимости и журнал этапа.
