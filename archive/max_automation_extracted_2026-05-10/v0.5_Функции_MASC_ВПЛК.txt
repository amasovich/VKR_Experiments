4. Управляющие конструкции 
4.1. IF...THEN...ELSE…ELSEIF…END_IF 
Команда IF определяет, что команда или группа команд будет выполнена только в том 
случае, если связанное с ней логическое выражение имеет значение 1 (истина). Если 
условие равно 0 (ложь), команда или группа команд не будет выполнена. 
Команда THEN обозначает конец условия и начало команды(команд). 
Команда END_IF отмечает конец команды(команд). 
ПРИМЕЧАНИЕ: Команды IF...THEN...END_IF могут быть вложены друг в друга для 
создания сложных команд выбора. 
Примеры IF...THEN...END_IF: 
Условие может быть выражено с помощью логической переменной.  
Если FLAG равно 1, команды будут выполнены; если FLAG равно 0 , они не будут 
выполнены. 
IF FLAG THEN 
   C:=SIN(A) * COS(B); 
   B:=C - A; 
END_IF; 
Условие может быть выражено с помощью операции, возвращающей логический 
результат. 
Если A больше B, команды будут выполнены; если A меньше или равно B, они не будут 
выполнены. 
IF A>B THEN 
   C:=SIN(A) * COS(B); 
   B:=C - A; 
END_IF; 
Пример IF NOT...THEN...END_IF 
Условие может быть инвертировано с помощью NOT (выполнение обеих команд при 0).

IF NOT FLAG THEN 
   C:=SIN_REAL(A) * COS_REAL(B); 
   B:=C - A; 
END_IF; 
Команда выбора ELSE 
Команда ELSE всегда следует за командой IF...THEN, ELSIF...THEN или CASE. 
Если команда ELSE следует за командой IF или ELSIF, то содержащаяся в ней команда 
или группа команд будет выполнена только в том случае, если соответствующие логические 
выражения команд IF и ELSIF равны 0 (ложны). Если условие команд IF или ELSIF истинно 
(равно 1), то команда или группа команд ELSE не будет выполнена. 
Если команда ELSE следует за командой CASE, то содержащаяся в ней Команда или 
группа команд будет выполне на только в том случае, если ни один из тегов не содержит 
значения селектора. Если какой -либо идентификатор содержит значение селектора, то 
Команда или группа Команд ELSE не будет выполнена. 
ПРИМЕЧАНИЕ: Команды IF...THEN...ELSE...END_IF могут быть вложены друг в друга в 
любом количестве для создания сложных Команд выбора.

4.2. WHILE…DO…END_WHILE 
Команда WHILE приводит к тому, что последовательность команд будет выполняться 
многократно до тех пор, пока связанное с ней логическое выражение не станет равным «0» . 
Если выражение ложно с самого начала, группа команд не будет выполняться вовсе. 
 Команда DO обозначает конец определения повторения и начало команды. 
 Команда END_WHILE обозначает конец команды. 
 В следующих случаях команда WHILE не может быть использована, так как она 
может создать бесконечный цикл, который приведет к сбою программы: 
1. WHILE нельзя использовать для синхронизации между процессами, например, в 
качестве «цикла ожидания» с внешне определенным условия завершения. 
2. WHILE нельзя использовать в алгоритме, если завершение условия конца цикла или 
выполнение команды EXIT не может быть гарантировано. 
Пример: 
X := 1; 
WHILE x <= 100 DO 
      X := x+4; 
END_WHILE;

4.3. REPEAT…UNTIL…END_REPEAT 
Команда REPEAT приводит к тому, что последовательность команд выполняется 
многократно до тех пор, пока связанное с ней логическое условия не станет 1. 
 Команда UNTIL обозначает условие завершения. 
 Команда END_REPEAT обозначает конец команды. 
  
 В следующих случаях команда REPEAT не может быть использована, так как она 
может создать бесконечный цикл, который приведет к сбою программы: 
1. REPEAT нельзя использовать для синхронизации между процессами, например, в 
качестве «цикла ожидания» с внешне определенным условия завершения. 
2. REPEAT нельзя использовать в алгоритме, если завершение условия конца цикла 
или выполнение команды EXIT не может быть гарантировано. 
Пример: 
x:= -1; 
REPEAT x:=x+2; 
UNTIL x>= 101 
END_REPEAT; 
 
4.4. CASE...OF...END_CASE 
Команда CASE состоит из выражения целочисленного типа данных (INT) (называемого 
«селектор») и списка групп команд. Каждая группа снабжена меткой, которая состоит из 
одного или нескольких целых чисел (INT, DINT, UINT, UDINT) или диапазонов 
целочисленных значений. Выполняется первая группа команд, метка которой содержит 
вычисленное значение селектора. В противном случае ни одна из команд не выполняется. 
Команда OF указывает начало метки. 
Внутри команды CASE может использоваться команда ELSE, команды которой 
выполняются, если ни одна  метка не содержит значение селектора. 
Команда END_CASE обозначает конец команды(команд).

ADD_AR 
ADD_AR(Array1, Array2) 
Описание: Складывает два массива одного размера поэлементно. Возвращает новый

SYSLOG(Result); 
(* Ожидаемый результат: Result = [5, 7, 9] *)

VAR 
    Value : UINT := 12; (* Двоичное представление: 1100 *) 
    BitPos : USINT := 3; 
    Result : USINT; 
END_VAR

SYSLOG(Result); 
(* Ожидаемый результат: Result = 1 *)

GET_BIT_MW 
GET_BIT_MW(Value, BitPos) 
Описание: Возвращает значение указанного бита из заданного значения. 
Выполняет действия аналогичные функции GET_BIT, отличие заключается в нумерации 
бит - нумерация бит (BitPos) начинается с нуля (номер младшего бита BitPos=0). 
Аргументы:

Описание: Функция возвращает значения из области регистров %MW с адреса Addr

Аргументы:  
 Addr: UINT — адрес в области памяти 
Возвращаемое значение:  
 Result — считанное значение 
Пример: 
VAR 
    Address : UINT := 10; 
    Result1 : UINT; 
    Result2 : REAL; 
END_VAR 
 
Result1 := GET_4X(Addr); 
Result2 := GET_4X(Addr); 
SYSLOG(Result);

PID_AQ 
Функция реализует полноценный ПИД -регулятор с непрерывным формированием 
управляющего воздействия. С помощью этой функции вы можете управлять 
технологическими процессами и системами с непрерывными в ходными и выходными 
переменными в системах автоматизации. Возможно управление как медленными 
(температура, уровень и т.д.), так и быстрыми системами управления (расход, скорость и 
т.д.). Регулятор может применяться как для поддержания фиксированного задани я, так и в 
многоконтурных системах управления в качестве каскадного/смешанного регулятора.  
Функция обеспечивает:  
 Режимы работы: ручной/автоматический; 
 Безударное переключение между ручным и автоматическим режимами; 
 Прямое (для увеличения регулируемого параметра повышается воздействие) 
или обратное (для увеличения регулируемого параметра уменьшается 
управляющее воздействие) формирование управляющего воздействия; 
 Независимую настройку коэффициента усиления (Р), времени интегрирования 
(I) и времени диффере нцирования ( D). Что обеспечивает полноценное ПИД 
регулирование или П/ПИ регулирование;  
 Ограничение управляющего воздействия; 
 Фильтрацию (задержку) дифференциальной составляющей ( D) управляющего 
воздействия.
