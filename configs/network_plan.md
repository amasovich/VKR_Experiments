# План сетевой адресации стенда

## Назначение

Документ фиксирует план сетевой адресации экспериментального стенда ВКР.

## Узлы стенда

| Узел | Обозначение | Роль | IP-адрес | Примечание |
|---|---|---|---|---|
| Инженерная машина Windows | ENG_NODE | настройка, мониторинг, обработка, архивирование | TBD | VS Code, TIA Portal, VPLC Studio, Python |
| mini-PC Linux | VPLC_HOST | исполнение VPLC / VPLC Server / Podman | TBD | MLLSE G2 Pro |
| Siemens S7-1200 CPU 1215C | HW_PLC | аппаратный эталонный PLC | TBD | 6ES7 215-1HG40-0XB0 |

## Предлагаемый стендовый сегмент

192.168.10.0/24

## Предлагаемые адреса

| Узел | IP |
|---|---|
| HW_PLC | 192.168.10.10 |
| VPLC_HOST | 192.168.10.20 |
| ENG_NODE | 192.168.10.30 |

> Примечания:
> - DHCP для стендового сегмента желательно не использовать.
> - На время измерений желательно отключать лишний внешний сетевой трафик.
> - Итоговые адреса будут уточнены после настройки оборудования.
